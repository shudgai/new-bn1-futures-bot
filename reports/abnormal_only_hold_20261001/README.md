The corresponding exit log explicitly identifies CLOSED_BELOW_MA5, quote 0.0043261 and peak price 0.0043391. See incident.json. A synthetic MA5-only regression reproduces that mechanism before the change and returns HOLD afterward; it is not presented as a historical tick replay.

## Current policy
LONG exits when the current candle's original open minus the latest quote reaches 1.2 times the immediately preceding closed 1M ATR; SHORT mirrors this with quote minus open. Equality triggers. The 1.2 multiplier is the stated implementation default, retained from the prior LONG flash-body threshold; the user did not explicitly select a number. The rule applies to first entries and subsequent positions, without requiring prior profit, MA/KC crossing, a doji, or candle closure. Intrabar highs/lows and entry price are not substitutes for the original candle open. Matching current-minute and immediately preceding closed-minute data are required; missing or stale candle data cannot create a new abnormal exit.

Ordinary pullbacks, MA5/MA3, KC middle, doji reversal, percentage giveback, peak retracement, and fixed partial-profit targets no longer independently authorize strategy exits. Initial ATR hard stops, account hard stops, and manual operations remain. The initial saved stop is preserved; retired profit-raised SLs are no longer mistaken for initial protection. An abnormal or valid initial-hard-stop pending close remains bound to the position identity and retries at the latest valid price after failure/restart. Old strategy pending states are revoked, while verified observed peaks are retained for display. No opposite order is opened by an exit.

The scanner now uses the same persistent evaluator as aggTrade/ticker. The old held-position state-machine branches have no independent exit authority. Daily entry halt does not disable held exits. Paper-account updates now enforce account/initial hard stops before their early valuation-only branch. Paper Channel Swing entries stop creating unused TP1 metadata; old TP1/breakeven metadata is removed during migration. No historical filled quantity is restored or fabricated. Existing entry rules, including long-wick rejection, remain.

The chart states the abnormal-body holding policy and labels the initial stop correctly. Exit logs use EXIT_ADVERSE_ABNORMAL_BODY with ADVERSE_BODY_1.2ATR; new triggers retain original open, previous ATR, candle time and trigger quote in position state. The existing single-flight close path is used; the Channel Swing reason prefix preserves strategy retry handling.
