# 最新峰頂即時鎖利

## 最新授權取代關係
使用者最後要求將平倉權限交給峰頂回吐即時鎖利。本輪取代先前25%／0.8ATR、中軌、MA3、十字反轉及收線Swing出口；尚未部署的三層／TP1平50%草稿取消，現在全部使用市價全平。帳戶硬止損、初始硬止損及手動操作保留，入口、資金、槓桿與冷卻不變。

## 目前規則
每筆有效aggTrade／ticker追蹤進場後實際觀察最高價（空單最低價），不以K線影線補峰值。曾順向推動至少1.5ATR，或扣雙邊費用與預估平倉滑點後峰值淨利／入場保證金至少5%，永久啟動本倉保護。

啟動後，從peak_price反向回落嚴格超過0.4ATR，或峰值淨利回吐達20%即市價全平。0.4ATR等於不單獨觸發，20%等於觸發；多空對稱。ATR固定取入場已保存ATR，若缺失才用首次取得的有效上一根已收線ATR，之後不因波動放大而放寬。所有退出使用即時報價，不等待當根收線。5%採入場保證金淨報酬，20%同樣按淨利計算，不混用價格漲幅或毛利。

尚未啟動時，中軌、MA3、十字、已收線Swing或固定2ATR均不能單獨平倉；獨立帳戶與初始硬止損繼續有效。保留更有利的原initial_sl，不放寬既有初始風控。

## 清理與執行
唯一狀態為peak_trailing_state。啟動、即時回調及帳戶更新同步清理持倉和metadata的instant_exit_state、closed_exit_state、doji_reversal_state、chandelier／Swing／舊保本與死抱旗標。保留可核對的真實峰值及匹配的初始硬止損待平；不繼承其他倉位峰值或舊策略待平。

pure_trend_v2、DualTrackExitStrategy與帳戶更新共用同一判定；收線／十字相容接口僅保留不產生出口的空操作。ticker不再進入掃描鎖或REST抓K；aggTrade沿用獨立串流。已有入場ATR時連K線快取都不讀取。有效報價5秒時效、逆序／進場前排除、持倉身分及close lock去重保持。已觸發待平與峰值持久化，重啟重試按新報價執行，不回填峰值成交價。

看板更新為「1M·峰頂即時鎖利（0.4 ATR／淨利回吐20%）」。日誌使用EXIT_REALTIME_PEAK_TRAILING，trigger區分PRICE_RETRACE_GT_04ATR與NET_PEAK_DRAWDOWN_20PCT，並記錄報價時間、實際判定價、峰值與判定延遲。初始硬止損沿用獨立原因。
