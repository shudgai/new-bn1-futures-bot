# Third-open chase limit

The user explicitly chose a price-distance limit from the third candle's open, with no opening-seconds deadline. The implementation default is 0.10 times the second candle's closed ATR; the user did not specify that numeric multiplier.

For LONG, latest quote minus the original third candle's open must be <= 0.10 * second closed ATR. SHORT mirrors this with original third open minus quote. Equality is allowed, with relative 1e-12 floating-point tolerance. A favorable-side quote is not considered chasing, but still needs the existing outside-rail and candle-validity rules. No 5/10-second timeout was added; ordinary market-data freshness and settlement checks remain.

The anchor belongs to the validated original breakout pair. Later continuation and post-close reopening keep that pair's original third open and second ATR instead of resetting the limit at each new candle or using the forming ATR. Missing actual third-candle data cannot authorize entry. Beyond-limit quotes return BLOCKED_THIRD_OPEN_CHASE without adding a persistent lock; valid quotes can recover. Signal generation, scanner, idle strategy, engine submission revalidation and account/exchange boundaries use the same contract. The final account evidence includes third_bar_id, third_open, third_reference_atr, max_chase_atr and chase_atr. This is a quote admission rule, not a guarantee of the eventual market fill price.

Held exits and the preceding abnormal-only policy are unchanged. Long-wick rejection and existing risk/deduplication rules remain. The test base live candle was changed to a valid near-open quote so existing wick tests still test their original boundaries; their assertions were not relaxed.
