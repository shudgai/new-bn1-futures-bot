## 🛑 規則一：大週期趨勢判定與【MSB 極速一鍵轉向】(Macro Trend & Instant Reversal)

1. **大結構絕對優先 (HH / HL / LH / LL)**：

   - **順勢硬性一票否決**：
     - **大週期牛市**：100% 一票否決所有 `OPEN_SHORT`（賣空）指令！
     - **大週期熊市**：100% 一票否決所有 `OPEN_LONG`（買多）指令！

2. **MSB 結構破位極速一鍵轉向 (解決大週期指標滯後 - 核心條款)**：
   - 嚴禁單純等待長週期均線或 KC 通道慢吞吞轉向！
   - **熊市轉牛市 (BEARISH ➔ BULLISH)**：當 K 棒實體收盤價 **強勢突破前波下殺關鍵高點（Lower High, LH）** 時：

   - **牛市轉熊市 (BULLISH ➔ BEARISH)**：當 K 棒實體收盤價 **強勢跌破前波拉升關鍵低點（Higher Low, HL）** 時：

## 🔴 規則三：空頭（SHORT）進場與【追空+斜率】三重一票否決

   - 🚫 **斜率否決**：若 `MA3 斜率走平或向上 (MA3_Slope >= 0)`（MA3 正在向上勾起），100% 一票否決開空！
   - 🚫 **偏離過大否決**：價格已急跌觸及 KC 下軌且負乖離過大（下殺尾聲），100% 強制攔截追空！

## 🛑 規則四：即時 MA5 75° 急速反轉與安全反手

1. **訊號計算（不得以圖表像素估角）**：
   - 僅使用有效、最新的 1m 即時報價與明確標記為 LIVE 的當根 K 棒；缺資料、過期、非 1m 或收線狀態不明時，訊號為 `NOT_TESTED`，不可猜測。
   - 依系統定義計算：`MA5_live = MA5_current + (quote - current_close) / 5`，`angle = degrees(atan((MA5_live - MA5_previous_closed) / previous_closed_close * 1000))`。
   - `angle >= 75°` 為急速向上訊號；`angle <= -75°` 為急速向下訊號。這是正規化斜率門檻，不是截圖上的幾何角度。

2. **持倉急轉出場（不等待中軌或當根收線）**：
   - 持有多單且有效即時角度 `<= -75°`：立即提出 `CLOSE_LONG`；持有空單且角度 `>= 75°`：立即提出 `CLOSE_SHORT`。
   - 此訊號優先於一般 KC 中軌斜率出場候選；不需要額外 K 棒確認或最小 K 棒實體。帳戶硬風控及本地最終出場 Gate 照常生效。
   - 已收線資料另可辨識三點峰谷：峰頂為轉折棒未創更高點、確認棒收盤跌破前棒低點；谷底反向對稱，確認棒收盤突破前棒高點。若本地結構 Exit Gate 確認授權，立即提出平倉候選，不等待 KC 中軌；不得以未收線 K 棒宣稱三點已確立。

3. **反手需經本地 Gate，不可由視覺模型直接授權**：
   - 出場成功且系統確認實際 FLAT 後，才立即評估相反方向；不等待額外確認 K 棒，但方向、Master、Macro Candle Structure、帳戶及下單安全 Gate 仍須全部通過。
   - 任一 Gate 拒絕或狀態未確認時保持空倉，不可繞過 Gate、直接呼叫下單 API，也不可假設反手已成交。
   - 同一標的、同一根 1m K 棒的 MA5 急轉訊號只允許一次執行嘗試；訊號鎖須持久化以防重複下單。

4. **其他出場規則**：
   - KC 中軌斜率等既有出場條件仍依本地策略 Gate 執行，不因新增 MA5 訊號而刪除或放寬。
   - 不可單憑靜態截圖推定即時角度、成交價或已實現盈虧；沒有可驗證資料時明確回報未知。
