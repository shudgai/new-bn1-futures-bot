# KC Band Expansion Gate

Every automatic Channel Swing entry, including impulse, next-candle launch, second/third candle and normal Trigger A/C, requires current KC width strictly greater than preceding width. LONG requires rising upper rail; SHORT requires falling lower rail. Equal/contracting width is rejected, without exemptions. Invalid or noncontiguous rail data fail closed. The final account firewall reevaluates the same contract with refreshed market data. Existing MA5, post-profit and account controls remain.
