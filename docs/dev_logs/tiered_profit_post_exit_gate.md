# Tiered net ROI locking and post-profit reentry gate

Latest explicit user specification restores tiered profit locking and prohibits same-side peak/trough chasing after successful profit exits. Shared Channel Swing peak state observes UI net ROI (net estimated PnL / margin): >=5% allows1.2 percentage points giveback; >=10% allows2.5 points; >=15% allows20% of highest ROI. Highest reached tier applies, peak state persists, and already authorized pending exits retry. PROFIT_LOCK_T1/T2/T3 pass realtime/account whitelists and the existing soft minimum-hold lock. Existing confirmed pivot and abnormal exits remain, with account position hard stops still disabled.

Successful close trades persist last_profit_exit_timestamp, last_profit_exit_side and last_profit_exit_peak_price. Trades are the durable authoritative event store already serialized by both accounts. Profitable pivot closes also record the observed price extreme. Testnet profit closes require full filled status/quantity before recording success; partial/unknown responses retain the position, no event, and existing retry behavior. No event is created by signal evaluation or failed close. Invalid extreme evidence is recorded as invalid and reentry fails closed.

POST_PROFIT_LOCK_GATE is shared by check_entry_gates and the separately authorized second/third entry path, so that relaxed path cannot bypass it. Same-symbol same-side entries are blocked for240 seconds. Then latest closed price must strictly exceed the previous long peak / break the previous short trough. Structural constraint expires after900 seconds or an adverse closed KC middle crossover after the exit. Cooldown always takes precedence over structural reset. The immutable historical event remains in trade history; the derived live restriction becomes inactive after reset/expiry, avoiding erased audit history. Opposite-side entries do not inherit this restriction. Market identity/finality, account risk, quote checks and fill deduplication remain.

Validation:138 targeted tests passed for tier boundaries/upgrade, long-short symmetry, restore/retry, exact240-second cooldown and900-second expiry, strict extreme equality blocking, post-exit-only middle reset, second/third no bypass, actual paper close/save/reload, real testnet account with mocked complete/partial fills, and active CAP/lobster policy / entry boundary regressions. Tests make no real trading orders. Earlier policy-specific percentage-lock-disabled tests are superseded by this explicit user policy.
